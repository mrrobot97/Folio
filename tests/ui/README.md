# 产品 UI 主机验证

从仓库根目录运行 `./tests/ui/run.sh [输出目录]`。默认输出 `/tmp/folio-ui-host`，包含测试程序、PGM 原始图和 PNG 预览；不写设备、不联网、不安装依赖。需要系统 C 编译器和 Python 3 标准库。

测试直接编译 `app_folio_home.c`、`app_folio_stats.c`、`app_folio_settings.c` 、`app_folio_sleep.c`、`app_folio_storage.c` 和 `folio_ui.c`。系统读数、阅读状态、导航目标和显示提交使用明确的测试替身；用于画面的“山间来信”等是测试 fixture，生产代码不包含伪造的统计或图书。

覆盖内容：

- 使用同一份生产页面回调，验证 render 不调用硬件/存储读取。
- 首页书架、继续阅读、统计三个入口独立；日历与明细往返保留选中日期。
- 2024–2035 全部日期格均位于屏幕内；闰年、世纪年、跨年日期正确。
- 小于一分钟的正时长和零时长区分；未知当前日期不能进入“今日”。冷启动未校时仍可查看已有日期历史。
- 首页/统计进入时传当前单调时间，留屏跨午夜仅在日期改变时重绘，保留历史选日；FAST 后的日期更新不补计睡眠时间。
- 选日的生产局部绘制与整页重新绘制完全一致；实际变化像素均在旧格、新格、明细的合并包围区域内。
- FAST/ECO 设置、传感器不可用时禁止拿起唤醒、保存失败保留旧值；休眠/关机只产生主循环请求。
- 存储重试和进入页面均不格式化；初始化必须经过两次确认；取消与确认期间变为已挂载均阻止初始化。成功后调用阅读服务恢复钩子。
- 地址和未定义行为 sanitizer 均启用；编译警告作为错误。

日历相邻日期切换仍绘制旧格、新格和明细三个脏区域，但提交前合并为一个包围矩形，GL16 提交次数由 **3 次降为 1 次**。测试的 10 月 9 日→8 日场景提交包围区域 **389,360 像素（全屏 46.81%）**；其他日期的包围面积随位置改变。这是逻辑提交面积，不是物理扫描面积、耗时、功耗或残影证据。生产提交继续使用官方 GL16、原波形、驱动错误恢复与周期清理；周期计数可能将某次区域刷新升为 GC16。

布局以稳定 `v0.4.2` 为基线；H01/H02/ST01/ST04/ST-DAY/S01 与 v0.4.1 相同。测试采用仓库内 OFL 字体 `ChillDuanSansVF.ttf` 和上游 `stb_truetype` 光栅化。主机替身不实现设备的可变字重、覆盖率 gamma、PSRAM 字形缓存和物理旋转；PNG 用于布局和文字边界检查，不能视为面板最终字重或墨色验收。设备页仍通过官方字体 API 绘制；共享 UI 将设计稿 CJK em 字号转换为该 API 的 ascent-descent 像素高度。

当前明确差异：官方基线没有可复用的全局书签管理，因此首页快捷项为可用的“统计”；未获取可靠导入时间的图书列表名为“本地图书”。封面使用书名生成的中性图形，不冒充 EPUB 封面。字体、TF 状态与诊断下级页仍复用官方入口，不能声称整套 354 张画板已全部重建。
