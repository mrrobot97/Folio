# 电源生命周期主机故障测试

运行 `./tests/power/run.sh [输出目录]`，默认产物在 `/tmp/folio-power-host`。需要系统 C 编译器，不联网、不安装依赖、绝不操作设备。测试失败返回非零，不能用“测试已运行”替代通过结论。

测试直接编译生产 `firmware/main/folio/folio_power.c` **和** `firmware/main/sleep.c`。没有替换 `enter_lock_and_sleep_mode()`、`app_enter_host_sleep()` 或失败重试逻辑。硬件、输入、时间、文件读取、保存服务和绘制原语是测试替身；驱动调用被计数。模拟 PMU 断电用 `setjmp/longjmp` 终止执行，避免真实实现成功下电后的永久等待，不触及任何 GPIO、串口、I2C 或供电。

覆盖：

- ECO/OFF 保存失败时不进入锁屏、不发送 PMU 断电指令，自动重试有两次与两秒门槛。
- 手动重试另启一轮有限保存；返回编辑、触摸取消及电源键取消。
- FAST 允许保存失败后保留内存进入浅睡，状态必须仍显示未保存；壁纸失败不能隐藏记录失败。
- 传书忙时不发起保存或断电；保存后至最终命令前传输状态变化也应拦截。
- 进度、统计、草稿七种失败组合及下一轮变化分别显示，不能互相覆盖。
- 初始仍按住的触摸不提交；按钮移出、移出后移回、多指和输入读取失败均取消当前接触。
- 显式关机覆盖当前 FAST 偏好；PMU 拒绝命令时显示失败，不认定已关机。
- 有未应用草稿时“返回编辑”调用专用 RAM 会话恢复；资源缺失保持错误页，用户可重试或电源键取消，不错误切页。实际草稿数据不被旧盘覆盖的验证属于 reader 测试，本套只验证编排与来源路由。
- 地址/未定义行为 sanitizer 与 `-Wall -Wextra -Werror`。

测试验证控制流、调用次数及用户可见状态，不验证真实写入持久性、面板效果、PMU 协议可靠性或实际功耗。存储掉电一致性由阅读记录测试负责，硬件仍需要单独验收。
